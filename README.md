# DataContainers

Учебный проект (Solution) на C++ и C#, посвященный ручной реализации динамических структур данных. Внутри подробно разобраны односвязные и двусвязные списки, механизмы оптимизации поиска по индексам, кастомные прямые и обратные итераторы, а также интеграция с Range-based циклами.

---

## Реализованные контейнеры и модули

### 1. List2 (Полноценный двусвязный список на C++)
Продвинутая ручная реализация двусвязного динамического списка, где класс `Element` объявлен внутри пространства имен (вложенный класс) основного класса `List`. Каждый узел хранит три поля: `Data`, указатель на следующий элемент `pNext` и указатель на предыдущий элемент `pPrev`.

* **Оптимизация поиска по индексу:** В методах `Insert` и `Erase` реализован алгоритм ускоренного поиска. Список делится пополам (`size / 2`). Если искомый индекс находится в первой половине, итерация узлов начинается с головы (`Head`) через `pNext`. Если во второй — перебор идет с хвоста (`Tail`) в обратную сторону через `pPrev`. Это сокращает количество шагов вдвое.
* **Двунаправленные и кастомные итераторы:**
  * `Iterator` — прямой итератор для перебора элементов от `Head` до `Tail`. Реализованы префиксный `operator++()` и постфиксный `operator++(int)` инкременты.
  * `ReverseIterator` — обратный итератор для прохода от `Tail` до `Head`, где оператор `++` смещает указатель назад через `pPrev`.
  * Благодаря методам `begin()`, `end()`, `rbegin()` и `rend()` контейнер полностью поддерживает циклы `for (int i : list)`.
* **Управление узлами:**
  * `push_front` / `push_back` — добавление элементов. При вставке в пустой список `Head` и `Tail` замыкаются на один узел. При добавлении к существующим — новые узлы перенаправляют связи `pNext` и `pPrev`.
  * `pop_front` / `pop_back` — корректное удаление крайних узлов с перепривязкой указателей соседних элементов и вызовом `delete`.

### 2. ForwardList (Односвязный список на C++)
Линейный односвязный список, где узлы связаны только в одну сторону (`pNext`).
* Реализован контроль за выделением памяти: конструкторы и деструкторы элементов логируют адреса указателей `this`, а глобальный счетчик `Element::count` отслеживает количество живых объектов.
* Поддерживает инициализацию через `std::initializer_list` (фигурные скобки) и глубокое копирование через конструктор копирования и оператор присваивания `=`.
* Имеет встроенный метод `reverse()` для разворота цепочки элементов через буфер.

### 3. List (Базовая модель двусвязного списка)
Начальный проект двусвязного списка, где обкатывалась базовая логика связывания узлов через поля `pPrev` и `pNext` при добавлении элементов в конец (`Add`) и выводе на экран.

### 4. DataContainers (Заготовка на C#)
Проект консольного приложения .NET для сравнения ручного управления указателями в C++ с работой ссылочных типов данных под управлением сборщика мусора (Garbage Collector).

## Настройка сборки и конфигурации отладки

1. Откройте проект в Visual Studio.
2. В файлах решений логику работы можно переключать через условную компиляцию:
   * В `List2/main.cpp` макрос `#define BASE_CHECK` активирует ручной ввод размера списка, генерацию случайных чисел через `rand() % 100`, а также интерактивную проверку методов `Insert` и `Erase` по индексам.
   * В `ForwardList/main.cpp` макрос `#define DEBUG` включает подробную трассировку вызовов `EConstructor` и `EDestructor` в консоли.
